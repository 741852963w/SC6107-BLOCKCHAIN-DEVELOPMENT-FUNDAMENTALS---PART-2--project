# User Guide

## Quick Start
1. Open the frontend dashboard (`/`).
2. Navigate to `Raffle` or `Dice`.
3. Follow the game flow shown on each page.

## Raffle User Flow
1. Enter raffle with required value.
2. Wait for draw phase.
3. Observe winner settlement and payout.

## Dice User Flow
1. Place dice bet with chosen parameters.
2. Wait for randomness response.
3. Observe win/loss and payout outcome.

## Troubleshooting
- If transactions fail, verify RPC URL and account balance.
- If callback is delayed, verify local coordinator and request status.
- If frontend is unavailable, run `npm run dev` in `frontend`.
